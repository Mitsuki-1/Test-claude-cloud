# Caramell Uzbekistan — сайт

Лендинг, каталог с корзиной и раздел «Мамам» для официального магазина детской одежды Caramell в Узбекистане.
Языки: русский и узбекский (латиница). Заказ оформляется в Telegram @Caramell_Uzbekistan готовым сообщением или по телефону.

## Страницы
- `index.html` — главная: видео/слайд-шоу, преимущества, категории, хиты, lookbook, опт, отзывы, контакты
- `catalog.html` — каталог: категории, пол, размер, поиск, сортировка, карточка товара, корзина
- `moms.html` — «Мамам»: калькулятор размера, чек-лист в роддом, подбор подарка, советы по уходу

## Запуск
Никакой сборки не нужно. Откройте `index.html` в браузере или запустите локальный сервер:

    python3 -m http.server 8000

## Автообновление каталога и фото
GitHub Actions (`.github/workflows/pages.yml`) публикует сайт при каждом push, раз в час по расписанию и вручную (Actions → Deploy site to GitHub Pages → Run workflow). Перед публикацией выполняются два скрипта, и если данные изменились, они коммитятся обратно в ветку:

- `scripts/sync_telegram.py` — забирает до 48 последних фото из канала [t.me/Caramelluz](https://t.me/Caramelluz) в `assets/tg/` и пишет `js/data/telegram.js`. Канал публикует в основном видео, поэтому если фото не хватает, берутся обложки видео (сначала из постов с ценой). Посты с поздравлениями, опросами и адресами пропускаются. Эти фото используются в галерее, плитках категорий, слайдах hero, блоке «Почему Caramell» и для товаров c101–c104 (по цене в тексте поста).
- `scripts/sync_billz.py` — забирает товары из BILLZ 2.0 в `js/data/billz.js`. Если файл заполнен, сайт показывает эти товары вместо демо (c101–c103 остаются для конструктора выписки и «хита недели»). Без секрета шаг просто пропускается.

Запуск вручную:

    python scripts/sync_telegram.py
    BILLZ_SECRET_TOKEN=... python scripts/sync_billz.py
    python scripts/test_sync_billz.py   # проверка на тестовом ответе API, без ключа

### Как подключить BILLZ
1. **Получите секретный ключ API в BILLZ.** Скрипт входит через `POST https://api-admin.billz.ai/v1/auth/login` с полем `secret_token`. Точного пути к этому ключу в кабинете BILLZ мы не знаем: обычно такие ключи находятся в разделе настроек или интеграций. Если не найдёте, напишите в поддержку BILLZ: «нужен secret_token для API v2 (api-admin.billz.ai)».
2. **Добавьте ключ в GitHub:** репозиторий → Settings → Secrets and variables → Actions → New repository secret → имя `BILLZ_SECRET_TOKEN`, значение — ключ. В код сайта ключ не попадает.
3. Необязательно: чтобы брать цены и остатки только определённых магазинов, на той же странице во вкладке **Variables** создайте переменную `BILLZ_SHOP_IDS` со списком id магазинов через запятую.
4. Запустите workflow вручную (Actions → Run workflow) и проверьте лог шага «Каталог из BILLZ».

### Как товары из BILLZ попадают на сайт
- **Скрываются** товары без остатка во всех магазинах и товары без фото (показать: переменная `BILLZ_SHOW_OUT_OF_STOCK=1` / `BILLZ_SHOW_NO_PHOTO=1`). Количества на складе в публичные файлы не попадают.
- **Одна карточка на модель и цвет.** Артикулы магазина устроены как `МОДЕЛЬ.ЦВЕТ.РАЗМЕР` (`TE1313.GRI.68-74`), каждый размер — отдельный товар в BILLZ; на сайте они собираются в одну карточку с выбором размера. Варианты с `parent_id` тоже объединяются.
- **Название и категория** определяются по турецкому названию: `Tulum` → «Комбинезон», `2 li Takım` → «Комплект (2 шт.)», `10'lu Set` → «Набор на выписку (10 шт.)», `Şapka` → «Шапочка» и т. д. (таблица `TYPES` в `scripts/sync_billz.py`). К названию добавляются бренд и цвет: «Комплект (3 шт.) Leo King · голубой». Если вместо названия стоит артикул, тип берётся у других товаров с теми же буквами модели (TE…, TKE…). Нераспознанное попадает в «Аксессуары и уход» и выводится в логе шага «Каталог из BILLZ» — по нему удобно дополнять таблицу.
- **Размеры** берутся из атрибутов «Размер»/«размер 1», из артикула или из названия: `56-62`, `6_9`, `6-12 AY`, `2-3 года`, `4 yaş`, просто `6` (месяцы) — всё переводится в сетку сайта; мусор вроде `-`, `V1`, `MIX` отбрасывается.
- **Пол** — по словам `kız`/`erkek` в названии, иначе по цвету (розовый, сиреневый → девочкам; голубой, тёмно-синий → мальчикам).
- **Цена** — минимальная по выбранным магазинам; promo-цена становится ценой со скидкой, розничная — зачёркнутой.
- Посмотреть, какие поля, атрибуты и магазины приходят из API: Actions → **Inspect BILLZ catalog** → Run workflow (печатает только названия и счётчики).

## Как редактировать
- **Товары и цены** — `js/products.js` (демо-товары; при подключённом BILLZ заменяются товарами из `js/data/billz.js`)
- **Тексты RU/UZ** — `js/i18n.js`
- **Контакты** — `js/main.js` (объект `CONTACT`) и блоки контактов в `index.html`
- **Фото и видео** — см. `assets/README.md`
- **Цвета и шрифты** — переменные в начале `css/style.css`

## Публикация
Подойдёт любой статический хостинг: GitHub Pages (Settings → Pages → ветка), Netlify, Vercel.
